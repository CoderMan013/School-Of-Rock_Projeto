# SchoolOfRock

SchoolOfRock é um sistema de gestão para uma escola de música, desenvolvido em PHP com API REST e painel web. O projeto permite o controle de alunos, funcionários, cargos, mensalidades e pagamentos, com autenticação por JWT e banco de dados MySQL. A aplicação foi criada para organizar processos administrativos de forma prática, segura e eficiente.

A estrutura do sistema inclui o cadastro e gerenciamento de usuários, controle financeiro, autenticação de acesso e operações de CRUD para as principais entidades do negócio. Além disso, o projeto utiliza uma arquitetura modular, facilitando a manutenção, a expansão e a organização do código.

O objetivo principal é automatizar as atividades administrativas da instituição, reduzir erros manuais e melhorar a gestão de informações acadêmicas e financeiras.

## Tecnologias utilizadas
- PHP
- Slim Framework
- MySQL
- HTML, CSS e JavaScript
- JWT para autenticação

## Funcionalidades
- Cadastro e gerenciamento de alunos
- Cadastro e gerenciamento de funcionários
- Controle de cargos e funções
- Registro de cobranças e mensalidades
- Controle de pagamentos
- Autenticação de usuários
- API REST para integração e manutenção de dados

## Como executar
1. Importar o banco de dados localizado em `database/escolamusica.sql`.
2. Ajustar as credenciais do banco em caso necessário.
3. Instalar as dependências com Composer.
4. Iniciar o servidor local.
5. Acessar a aplicação no navegador.

## Objetivo do projeto
Proporcionar uma solução funcional para a gestão de uma escola de música, com foco em organização, eficiência e segurança dos dados.
